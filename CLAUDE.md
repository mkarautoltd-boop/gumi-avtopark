# Гуми Автопарк

Приложение за гумите на служебния автопарк: сезонна смяна (летни ↔ зимни), собствен склад за гуми, рейсове с бус до два сервиза, цени, справки.

## Как е направено
- `index.html` — цялото приложение (един файл: HTML + CSS + JS). Това е изходният код — редактира се директно.
- Хостнато в GitHub Pages: https://mkarautoltd-boop.github.io/gumi-avtopark/
- Сървър: Google Apps Script, свързан с Google таблица „Гуми Автопарк“. Кодът му е в `server/Code.gs` (поставя се ръчно в Apps Script).
- Адресът на сървъра е в `index.html`: `const API_URL = 'https://script.google.com/macros/s/…/exec'`.
- Колите идват от таблицата на пътната книжка (само четене), ID в листа „Настройки“ → `ROAD_BOOK_ID`.
- Иконите: `icon-192.png`, `icon-512.png`, `apple-touch-icon.png`, `manifest.json`.

## Пускане на промени
- Приложение: промяна в `index.html` → commit → push в `main` → GitHub Pages го качва за ~1 мин.
- Сървър: промяна в `server/Code.gs` → вдигни `SERVER_VERSION` → дай на потребителя целия файл. Той го поставя в Apps Script → 💾 → Deploy → Manage deployments → ✏️ → Version: New version → Deploy (адресът остава същият).
- Ако страницата иска нов сървър, проверявай `DB.version` и покажи ясно съобщение, когато сървърът е стар.

## Правила за работа с потребителя
- Пише на български; отговаряй на български, кратко и ясно.
- Не редактира код сам — винаги давай ЦЕЛИЯ файл за поставяне (никога „смени ред X“).
- При всяка нова идея: провери дали е възможно → направи → пробвай → покажи резултата (снимка/пример) → питай дали да го пусне. **Push/пускане само след „Давай“.**
- Винаги тъмна тема, мобилен изглед + изглед за лаптоп, долното меню не мърда.

## Важни понятия
- Роли: администратор, служител, шофьор на бус.
- Цени за смяна: по сервиз × вид кола (лека / джип / бус) × диаметър (R13–R22), „Монтаж и демонтаж“ и „Смяна с джанти“, плюс обща цена за размер без цена.
- Размерите често са написани като `185/65/15` или `225/65/16С` (кирилско С) — `diamOf()` ги разпознава.
- Справка: разход за смяната (прогноза), гуми за купуване с ориентировъчни цени от интернет (`TIRE_EST`, 24gumi.bg, 29.10.2026), PDF справка, запитване за оферта (PDF).
- Рейс → „💬 Съобщение за Viber“: готов текст с колите по сервизи (телефон и линк към картата на сервиза се пазят в localStorage).
